Overview

This analysis calculates ship-strike risk for Rice’s whale (Balaenoptera ricei) in the Gulf of Mexico, using:

  • Whale densities: Litz et al. (2022) hexagonal grid model
  • Vessel traffic: 2023 AIS data from Benioff Ocean Science Laboratory
  • Risk model: Conn & Silber (2013) speed-based risk factors

Risk Factor Model

Based on Conn & Silber (2013), strike risk increases non-linearly with vessel speed:

1.3 Company Fleet Summary

# query company traffic in critical habitat
company_sql <- "
  SELECT
    c.company,
    COUNT(DISTINCT sc.mmsi) AS n_ships,
    COUNT(*) AS n_records,
    SUM(sc.dist_travelled_km) AS total_km,
    SUM(sc.hours) AS total_hours
  FROM ship_cell sc
  JOIN ship s ON sc.mmsi = s.mmsi
  JOIN company c ON s.operator ILIKE '%' || c.operator_lookup || '%'
  GROUP BY c.company
  ORDER BY total_km DESC
"

company_summary <- DBI::dbGetQuery(con, company_sql)

2.1 Traffic by Speed Bin and Cell

Show code 
# this query aggregates traffic by cell and speed bin
# for intersection with whale densities
traffic_sql <- glue("
  SELECT
    c.cell_id,
    {get_speed_bin_sql()} AS speed_bin,
    SUM(sc.dist_travelled_km) AS total_km,
    SUM(sc.hours) AS total_hours,
    COUNT(DISTINCT sc.mmsi) AS n_ships
  FROM cell c
  JOIN ship_cell sc ON c.cell_id = sc.cell_id
  WHERE sc.avg_speed_knots IS NOT NULL
  GROUP BY c.cell_id, speed_bin
")
